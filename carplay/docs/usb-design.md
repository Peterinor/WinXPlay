# USB 与会话接入

Windows 通过 Apple 设备服务提供 USBMUX/配对通路，WinCE 使用自有 USBMUX 驱动和系统网络后端。配件认证身份与手机信任记录是不同材料，不能互相替代。

MRN 的原厂 NCM 匹配及注册兼容条件见 [设备说明](../../docs/devices/mrn.md)。控制通路建立后仍需要实际网卡、IPv6 地址和媒体服务端点；驱动注册成功不能替代真实网络验证。

收到媒体可用通知而网络地址尚未就绪时，当前实现继续处理控制流并查询地址，避免仅因暂时没有地址就立即重启全部配对。地址就绪后发布端点并计算媒体启动期限。真实媒体数据与物理输出需要分别验收。

通用 CE 驱动通过系统 API 注册；仅 MRN 构建启用已知 F3.21 空实现的受限注册表回退。MRN 的 NCM 注册规则和接收端启动准备也由设备层提供，不作为所有 CE 设备的默认流程。

Windows 使用步骤见 [Windows 指南](../../docs/guides/windows.md)；MRN 的设备部署见 [MRN 安装](../../docs/guides/mrn-install.md)，阶段定位见 [故障排查](../../docs/guides/troubleshooting.md)。原厂驱动分析、抓包及逐轮配对调试属于研究记录，不在本说明中重复维护。
