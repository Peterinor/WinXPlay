# 兼容性与验证边界

以下区分已实现能力、合成回归与指定设备上的实测结果。构建成功或离线测试通过不等于手机和实车验收通过。

## 平台实现与设备验证

WinCE 提供系统 API、窗口、USB、wave 和 DirectShow 的实现基础。CeGeneric 未配置视频后端，没有可直接使用的完整接收端验证；不能套用 MRN 的滤镜、音源、输入桥接或固件兼容结论。CeHost 是桌面测试目标，不是已支持的 CE 设备。

下表比较 Windows 接收端与 **MRN F3.21 设备配置**。右列只适用于该设备与固件，不代表 WinCE 平台的通用能力。

MRN 当前默认关闭 CarPlay 音频输入、输出，保留 USB 画面与触控，音频使用原车蓝牙。相关取舍、带宽说明及剩余卡顿见[MRN 使用提示](guides/mrn-usage-notes.md)。下表中的音频实现不表示默认启用。

| 能力 | Windows | MRN F3.21 设备配置 |
| --- | --- | --- |
| 有线主屏接收 | 指定本机环境有 iPhone 720p/1080p 历史通过记录 | 已有实车持续会话记录，动画和滚动仍卡顿；最新无日志、关闭音频的配套包待实车确认 |
| 视频后端 | Media Foundation + D3D11；本机离线和历史真机验证 | DirectShow 内存源 + 原厂滤镜；有限素材实际显示已验证 |
| PCM 输出 | 历史本机出声通过；不同轮次的蓝牙路径需分开解释 | 默认关闭；设备 1/TTS 已出声，但有偶发中断及主观音质差异，长期质量尚未验收 |
| AAC / 缓冲 AAC | 合成对端回归覆盖；不能扩大为所有手机场景实测 | 普通 AAC 系统 DMO 启动自检实车通过，该轮手机仍选择 PCM；AAC 音乐效果未验证。缓冲 AAC 不声明 |
| 触摸、控制器输入 | 软件与独立对端覆盖，桌面触摸有历史验证 | 用户确认触控恢复；短暂超时误取消点击已修正。完整按键映射和抢占恢复仍需实车确认 |
| 麦克风、电话与 Siri | 上行软件回归；真实通话及回声消除未验收 | 主程序上下行实测可听，但对端报告回声；录音机源同步生成含双方声音的原厂备忘录；两个缺陷未解决，Siri 尚未验收 |

| 自动重连 | 代码与合成对端覆盖 | 代码与模拟检查覆盖，长时间拔插稳定性待实测 |
| 无线、多手机、仪表副屏 | 未实现 | 未实现 |

## 使用这些结论

Windows 本地音频输出与 iPhone 直接蓝牙连接原车是两条不同路径。后者由电脑只显示画面，不能作为接收端音频解码、输出或端到端音画同步的验证。

MRN 有限 AV 素材的物理显示及主观声画同步已获现场确认；这不证明实时 CarPlay 延迟、硬件加速、长期音画同步或左右声道分离。驱动提交量、播放位置与渲染计数不是物理可见/可听的充分证据。

WinCE 构建和 WM5/CE5.1 模拟器结果不能泛化到 CE6、WEC7 或其他车机；Generic 是编译配置，不是已验证设备列表。Windows 历史结果也不能覆盖所有 GPU 和手机系统版本。
