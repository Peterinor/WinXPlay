# 发布

公开源码以本目录为根。发布前执行结构检查和适用平台的回归，并记录未覆盖的设备项。不要把研究工作区或 `.local/`、`build/` 整体压入源码包。

每个公开二进制版本应对应确定的源码提交或源码归档、构建配置、依赖版本、SHA-256 和已知问题。提供履行 GPL 所需的对应源码及构建脚本；第三方源码、许可和改动说明按实际分发情况提供。当前第三方清单是来源记录，不代表已经完成所有模块的来源审计。

本地部署包与公开 Release 分开准备。`package-usb-test.py` 可复制身份；HMI 补丁产物包含原厂程序内容；这些不能未经分发权和内容核查就上传。原厂固件、SDK、字库和真实身份不属于本项目 GPL 授权范围。

公开包必须排除真实私钥、配对记录、个人日志、设备标识与机器专用配置。不能用缺少对应源码、构建配置或校验记录的历史产物代替发布构建。

当前维护本地固定 `build/packages/工具名/` 输出，重新打包可更新它；公开版本则应保存不可变的发布文件，避免同一版本被覆盖后无法复现。首个公开版本采用 0.x，并分别说明 Windows 与 MRN 的成熟度。
