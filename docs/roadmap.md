# 开发路线图

## 当前优先级

1. 持续验证独立检出目录中的 Windows、ARM 和工具构建，防止引入本机或研究工作区的隐式依赖。
2. 完成依赖及代码来源审计，确认第三方 GPL 版本范围和可分发内容。
3. 按兼容性表验证 MRN 的持续手机投屏、音源、左右声道、输入及原厂恢复。
4. 单独验证有效麦克风人声、Siri/通话和全双工回声处理。
5. 验证重复拔插、长时运行、错误恢复、倒车和休眠场景，记录实际包版本。

## 后续演进

以实际设备需求推进移植。核心保持 C++03 与最小能力接口；平台私有实现可使用不同工具链。无线、多手机、仪表副屏和动态插件框架尚无实现承诺。
