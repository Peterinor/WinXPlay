# MRN 部署与更新

适用当前 MRN F3.21 适配。阅读 [设备约束](../devices/mrn.md) 和 [兼容性](../compatibility.md)，不要把编译包当成已验证的完整车机功能。

安装前先看[MRN 使用提示与技术取舍](mrn-usage-notes.md)。当前 MRN 默认关闭 CarPlay 音频输入、输出，声音使用原车蓝牙；USB 画面与触控保留，动画和滚动仍可能卡顿。

## 运行位置与入口

固定内部目录为 `\NAND_USER\WinXPlay`，主程序 `WinXPlay.exe`。同一 USB 口先用于部署，再接手机；运行依赖应留在内部存储。原厂 HMI 通过 `WinXPlayBridge.dll` 提供 BAND/输入/显示交接；只复制主程序不会给原厂 HMI 自动增加桥接钩子。

## 本地生成包

先构建接收端、USB DLL、file_ops 和配套桥接，按 [桥接说明](../../firmware/mrn/README.md) 验证并准备桥接产物。运行 `python carplay/scripts/package-usb-test.py --help` 查看明确的身份、配对和无日志参数。此脚本生成含外部身份的私有安装包，不直接用于公开发布。

包默认位于 `build/packages/winxplay_install/`。方案 A 使用 AutoLaunch，方案 B 使用 AUTOLAUNCH_PROD，每次选择一套。复制到 U 盘前检查包内说明及 fileops.txt 的全部目标路径。

## 部署、启动和采集

1. 退出相关程序，确保要覆盖的 DLL 没有被加载；已有 HMI 钩子与首次安装钩子是不同流程。
2. 将选定方案的目录放到 U 盘根目录，用默认 COPY 配置部署。文件工具按当前配置执行；检查每一项结果，不能只看程序退出。
3. 确认结果为 ALL_JOBS_COMPLETE。更新已加载 DLL 时按包内说明重启；不要在运行中替换它。
4. 需要单独启动时采用生成的 RUN 配置，它不重复复制；内部运行后拔出 U 盘接手机。
5. 需要采集时采用 collect 配置，按实际存在的日志调整，检查逐项结果。身份和配对文件不是诊断日志，不公开分享。

首次 HMI 补丁只支持构建器接受的原厂哈希，必须保留原件、补丁清单及可用恢复入口。普通更新包不等于刷机包，也不自动替换 HMI。恢复时使用与实际补丁匹配的原件/还原结果，不能混用其他固件。

程序返回原车界面时隐藏窗口并取消输入，手机连接与重连可继续。日志、窗口状态或心跳不证明原厂图层、音源和物理触摸已经正确交接。
