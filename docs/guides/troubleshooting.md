# 故障排查

先记录平台、固件、手机系统、程序版本/哈希和连接阶段，再定位对应组件。

| 阶段 | 检查点 |
| --- | --- |
| 启动失败 | 编译架构、缺失 DLL、OpenSSL 路径、身份配置；记录系统或程序显示的具体错误 |
| USB 控制通道不可用 | Windows 检查 Apple 服务；CE 检查自有驱动的 CMX1 打开错误、注册和真实 ATTACH；注册成功不等于设备枚举 |
| 手机信任/配对 | 解锁、授权提示、配对错误与身份是否持续；不要公开配对密钥 |
| 等待网络 | NCM 网卡、绑定、IPv6 链路本地地址和实际收发；仅有 ::1 不算网络就绪 |
| 等待画面 | 媒体会话、视频包、关键帧、解码及物理显示分别确认 |
| 有画面无声音 | PCM/AAC 协商、设备打开、队列分别检查；MRN 另查设备音源路由 |
| 麦克风无声 | waveIn 设备、实际采样及回听；非零数据也可能只是噪声 |
| MRN 返回原车异常 | 使用配套桥接版本，分别检查窗口、图层、输入取消和音源 |

带日志版本可生成 `auto-connect.plist`、`usb-connection.plist` 等连接状态。CE USB 驱动可生成 `usb-driver.log`；MRN 启动与音频恢复对应 `portable-startup.plist`、`audio-recovery.plist`，HMI 桥接对应 `A_BRIDGE.log`。实际生成与否取决于平台、功能阶段及日志构建选项。无日志版本仍保留屏幕提示和文件部署结果。

只分享最小脱敏日志。不要上传 identity、phone-pair 文件、完整运行目录或未检查的安装包。实车独立 AV/连接/输入测试见 [诊断入口](../../carplay/tools/mrn/README.md)。
