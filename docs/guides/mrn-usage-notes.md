# 标致 508 MRN 使用建议

## 建议怎么用

**CarPlay 用来看地图、操作界面，声音继续走原车蓝牙。** 当前 MRN 版本默认关闭 CarPlay 音频和麦克风，日常使用无日志配套包。连接手机时，请同时保持原车蓝牙连接。

**这套 MRN 适配如果开启 CarPlay 声音，音乐也会走原车的导航／语音通道。** 我们目前打通的是这条出声路径，尚未接入原车主音乐输出通道。结合实际听感和卡顿表现，日常听音乐建议继续用原车蓝牙。这是当前适配的限制，不是 CarPlay 本身只能使用导航声道。

如果想保留原车机、增加 CarPlay 地图和触控，可以使用这套方案；如果要求动画始终流畅、电话和 Siri 全部通过 CarPlay 稳定使用，目前还达不到。通话优先使用原车蓝牙免提，导航播报和 Siri 的声音去向需要实际确认。

## 实际测试怎么样

- **切到蓝牙后，画面好一些。** 视频卡顿有所减轻，但动画和滚动仍可能不流畅。
- **蓝牙音乐听起来更好。** 同一台车上，蓝牙音乐听起来更饱满；CarPlay 经导航／语音通道播放时偏尖锐，并有偶发中断。
- **CarPlay 麦克风还有问题。** 通话对端反馈有回声，而且会触发原车语音备忘录录音，所以暂时关闭。
- **AAC 暂时没有带来可验证的改善。** 车机解码自检通过了，但测试时 iPhone 仍选择 PCM 音频，没有实际用上 AAC 音乐播放。

## 我们推测是什么原因

**更可能是车机同时处理实时画面和声音时，处理余量不够。** CarPlay 除了解码和显示，还要接收、解密和处理音频；切到蓝牙后减少了这部分工作，可能因此让画面更顺。这与实测现象相符，但还没有定位到唯一瓶颈。

USB 2.0 的标称带宽不能代表车机实际传输速度，驱动和系统调度也可能造成等待。不过，目前没有证据证明是 USB 带宽被占满。原车 MP4 播放顺畅，也不能说明实时 CarPlay 一定同样顺畅，两者的处理和缓冲方式不同。

**音质差异可能与两条通道的声音处理不同有关。** CarPlay 使用导航／语音通道是已经确认的实现选择；它是否采用了不同的均衡、频响或其他声音处理，目前没有测定，不能把听感差异全部归因于某一项。

麦克风借用了原车录音机通路，目前还没有将麦克风采集与原厂录音业务分开，也没有完成回声消除。因此现阶段保留原车蓝牙音频，是实际体验更好的选择。

适用于 MRN F3.21。安装步骤见[安装说明](mrn-install.md)。
